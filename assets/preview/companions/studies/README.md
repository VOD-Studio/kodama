# 造型稿

每个角色一个文件夹，放该角色的图、生成提示词和说明。这些都是静态造型设计，不是运行素材；运行用的帧由 `scripts/assets/` 的脚本生成。

| 角色 | 文件夹 | 内容 |
|---|---|---|
| GPT | [gpt](gpt) | 幼年、少年、成年造型稿与提示词；成年稿是运行帧的造型参考 |
| Claude | [claude](claude) | 幼年、少年、成年终阶 |
| Grok | [grok](grok) | 幼年、少年、成年终阶 |
| GLM | [glm](glm) | 幼年、少年（选 v3）、成年终阶 |
| Kimi | [kimi](kimi) | 幼年、少年、成年终阶 |
| Gemini | [gemini](gemini) | 幼年、少年、成年终阶 |
