# 进化形态与像素画风

#6、#11、#14 的一部分。此前的进化只在同一副身体上加点缀（少年头顶一个色点、成年戴金冠），三个阶段几乎一样，进化分支也看不出区别。本文的设计让进化像宝可梦那样**改变整副身体**，并让分支决定外形。

规则（经验、性格、进化条件、扣费）不变，`rules_version` 不变；变的是外形如何由阶段与进化记录得出，以及像素画风本身。

## 外形体系

| 层次 | 来源 | 数量 |
|---|---|---|
| 身体 | 物种 × 阶段：幼体、少年、成年各一副身体，体型逐级变大、轮廓与特征都不同 | 8 × 3 = 24 |
| 少年特征 | 进入少年时选择的分支：好奇、温柔、稳健 | 3 |
| 成年特征 | 进入成年时选择的分支：贤者、守护者、漫游者、辉耀 | 4 |

成年外形由**成年分支决定剪影**，少年时的分支作为次要特征保留，所以每个物种有 1 种幼体、3 种少年、3 × 4 = 12 种成年外形，共 16 种，全部 128 种。

外形只由 `growth.lineage`（进化记录）决定：`[]` 幼体，`[少年分支]` 少年，`[少年分支, 成年分支]` 成年。

### 分支的视觉语言

部件按身体的锚点（头顶、眼、嘴、肩、腿根）定位，同一套部件适用于全部身体；材质颜色随分支变化，在机械与植物物种上同样成立。

| 分支 | 特征 | 位置 | 材质 |
|---|---|---|---|
| 好奇 | 头顶卷毛 | 中线最高处 | 物种的点缀色 |
| 温柔 | 下巴下方蓬松的围兜，向两侧蓬出 | 嘴下方 | 浅色绒毛 |
| 稳健 | 额纹，腿根两侧结实的绒毛 | 额头、腿根 | 深色花纹 |
| 贤者 | 一对弯角，额头嵌一颗光石 | 头顶两侧、眉心 | 紫水晶 |
| 守护者 | 圆顶肩甲与胸甲 | 肩、胸 | 钢 |
| 漫游者 | 背后展开的一对羽翼 | 肩后 | 天空色羽毛 |
| 辉耀（后天罕见） | 悬在头顶上方的光环，身旁闪光，点缀全部镀金 | 头顶上方 | 金 |

稳健的绒毛放在腿根而不是肩上，是因为肩甲与翅膀会盖住肩部：放在它们够不到的低处，成年后少年特征仍看得见。

## 画风规则

模板只画**剪影与细节**（身体、浅色、点缀、花纹、眼、嘴、腮红），描边与明暗由统一规则生成，所以 128 种外形风格一致：

- **描边**：透明且与填充 4 邻接的像素成为描边；胡须、闪光、字形等细节不产生描边。
- **明暗**：光从左上来。每种材质（身体、点缀、部件、浅色、花盆、光辉）的左上边缘提亮、右下边缘压暗，一像素宽的地方保持原色。
- **分层**：背后的部件（尾巴、翅膀、光环）、身体、身前的部件各自描边打光再叠加，部件与身体之间因此有一道描边。
- **对称**：身体只画左半边，渲染时镜像；尾巴、胡须等不对称部分是补丁。
- **基因**：只改变颜色、不改变像素布局。基因 0 偏移主色相，基因 1 调整明暗，基因 2 偏移点缀色相。

## 姿态与动画

`t` 为呈现时钟的刻度，一帧动作 = 2 个刻度。所有动作按身体中线定位，摇摆、抬脚与外形切换时身体不会跟着包围盒抖动。

| 姿态 | 表现 |
|---|---|
| 待机 | 在画布里来回走动：行走者左右脚交替抬起，悬浮者离地浮动并在地面投影，扎根者不位移、花盆以上左右摇摆；不定时眨眼（基因 4 错开节奏） |
| 注视 | 停下，眼神左右张望；悬浮者停止浮动 |
| 进食 | 笑眼、嘴一张一合，嘴下捧着的苹果一口口变小 |
| 玩耍 | 笑眼、向上跳起，脚前的球弹跳 |
| 睡觉 | 闭眼，身体缓慢起伏，头侧冒出上升的 Z |
| 受惊 | 一跳，眼睛睁大（眼白与瞳孔互换），头顶感叹号 |
| 生病 | 偏青灰，眼神无光，额边汗滴滑落，身体摇晃 |
| 进化 | 见下文 |
| 终结 | 去色、闭眼、头顶光环，坐在纪念台上，不再动 |

道具（苹果、球）自带描边，在任何体色上都看得清。

### 进化动画

32 刻度一个循环。前 24 刻度，进化前与进化后的外形以发光的白色剪影交替出现，越换越快（像宝可梦的进化）；后 8 刻度显示新外形的完整颜色，四周闪光一明一暗。幼体没有前一个外形，只有自身的剪影闪烁。

## 输入与兼容

- `sprite` 命令新增可选字段 `lineage`（进化记录），给出时以它决定阶段与外形；不给时按 `stage`（0、1、2）显示不带分支特征的基础身体，旧调用方不受影响。
- 进化记录与阶段对不上（例如少年阶段写了成年分支）时，退回按阶段显示，画面永远可以渲染，合法性由规则核心负责。
- 画布不小于 56×36 时任何外形与姿态都不会被裁切（最大的是展翅的成年形态）；待机会在画布里走动，需要更宽的画布，例如 96×40。
- 阶段与分支的类型从规则核心移到 `pet-term`（`pet_term::form`），由 `pet-core` 再导出，线上名称不变。

## 校验

`crates/core/pet-term/tests/pixel.rs` 的 13 项检查，「不看颜色」指只比较像素键位：

| 检查 | 含义 |
|---|---|
| 全部外形与姿态都能渲染，键都有颜色 | 8 物种 × 16 外形 × 9 姿态 |
| 进化改变身体，而不只是添加细节 | 每升一阶更高、面积至少大 30%，且旧剪影里有像素在新剪影中消失 |
| 分支各有外形 | 少年三种剪影互不相同；同一少年特征下四种成年剪影互不相同；12 种成年外形逐像素不同 |
| 部件贴着身体 | 除辉耀的光环悬在头顶上方外，没有浮空的部件 |
| 物种只看剪影就能区分 | 每个阶段 |
| 同一物种的姿态可区分 | 40 刻度的动作序列两两不同 |
| 眨眼与张望 | 注视时画面会变 |
| 移动符合身体结构 | 行走者双脚着地且会迈步，悬浮者不触地、会浮动并投影，扎根者花盆不动但会摇摆 |
| 进化动画 | 白色剪影中出现进化前与进化后两个外形，揭晓时有闪光 |
| 进化记录决定外形 | 不合法时退回按阶段 |
| 基因只改颜色 | 布局不变、调色板不同 |
| 确定性、极小画布不 panic | |

## 预览

```sh
cargo run -p pet-term --example sprites -- observe 0   # 写出 target/sprites.html：8 物种 × 16 外形
cargo run -p pet-term --example sprites -- evolve 9    # 进化动画中的一刻
```

改动身体模板或部件后，用它目视检查，并跑 `cargo test -p pet-term`。

## 后续

- **终端画风的阶段外形**：字符画目前所有阶段共用一副身体，下一步按同样的体系为三个阶段与分支提供字符外形。
- **精细画风**（#14）：沿用同一套外形体系与锚点，换成矢量或高分辨率位图。
- **物种特有的进化条件**：目前进化条件对所有物种相同，形态因物种而异；条件差异属于规则调整，需要评审与新的 `rules_version`。
- **基因影响更多特征**：例如花纹的有无与位置，需要保持「基因只在出生时决定、外形可复算」。
