# 装扮与场景

#17 的实现说明，规则来自[扩展玩法评审](extensions.md)第 1 节。装扮让每只宠物更有个性，但**只改变画面**：不改变身份、稀有度、基因、进化或任何数值（PRD AC-16）。

## 怎么得到

- **升级解锁**：2 级起每升一级得到一件，顺序固定。解锁由规则核心在每次结算时按当前等级补齐，所以无论升级来自喂食、玩耍还是活动奖励都一样，账号模式与本地模式一样，任何一端都能复算；重复结算不会多给。
- 评审规定物品来自奖励发放而不是出售或抽取：升级本身就是照料与活动的回报。之后的探险收藏（#18）会带来更多物品。
- 本功能之前已经升级的个体，在下一次结算时补齐解锁，当次就能穿上。

## 穿戴

- 动作 `{"equip": {"item": …}}` 穿上拥有的物品，替换同一槽位上的物品；`{"unequip": {"slot": …}}` 脱下，物品仍然拥有。两者都免费、可逆。
- 每个槽位至多一件：头、脸、身、背、背景。
- 装备时检查身体结构，不适合的返回 `incompatible_item`；没有的物品返回 `not_owned`。背包挂不到花盆里的芽苗身上，披风只有走路的身体撑得起来。
- 物种在出生时记录在宠物状态里（`Pet.species`），规则核心不需要调用方另外传入。本字段之前出生的个体没有物种记录，只能穿适合全部身体的物品。
- 逝去的个体拒绝一切动作，纪念形象保留逝去时的装扮。

## 存储

宠物状态新增两个字段，旧存档照常读取：

```json
{ "species": 3, "wardrobe": { "owned": ["round_glasses", "knit_scarf"], "worn": { "face": "round_glasses" } } }
```

衣橱为空时不写出，所以新出生个体的出生结果只多了 `species`；黄金出生向量比较的是派生出的身份、稀有度、物种与基因，不受影响。装扮不改变任何结算数值，因此不提升 `rules_version`（见[版本策略](versioning.md)）。

## 画面

- 物品和进化特征一样**按身体锚点定位、按身体大小伸缩**：眼镜围着眼睛的实际像素画一圈，围巾的宽度随肩宽，帽子与花环随两眼的间距，披风从肩垂到脚边。所以一件物品适用于全部 24 副身体，从幼体到展翅的成年形态。
- 描边与明暗沿用统一规则（光从左上来），和身体、进化特征风格一致。眼镜的框与镜片不产生描边，眼睛照常露出、照常眨眼与转动。
- 背景是画满整块画布的场景：晴日草地有太阳和慢慢飘的云，星夜有月亮和闪烁的星星；天空分段之间用棋盘格过渡，不出现生硬的横线。
- 纪念形象（`end` 姿态）连同装扮一起去色。
- `sprite` 与 `frame`（`blocks` 画风）都接受 `outfit`；网页 `mountPet` 与终端嵌入在宠物对象上传 `outfit`（即 `wardrobe.worn`）。不适合这个身体的物品不画。
- `cargo run -p pet-term --example sprites -- outfits` 导出 8 个物种的幼体与成年 × 每件物品与两套搭配的总览图，改动美术后目视检查。

## 校验

- 规则（`pet-core/tests/wardrobe.rs`，9 项）：出生记录物种、衣橱为空不写出；旧存档读取；每级解锁一件且不重复；照料升级同样解锁；只能穿拥有且适合身体的物品；物种不明时只能穿通用物品；穿脱不改变任何数值；逝去后不能改；旧个体补齐解锁后当次能穿。
- 画面（`pet-term/tests/outfits.rs`，6 项）：目录与代码一致；每件物品在每个适用的物种与阶段上都改变画面且不碰画布边缘，不适用的不画；眼镜不遮住眼睛；背景铺满画布并随时钟变化；纪念去色；终端半格画带上装扮。
- 三端一致的转录包含穿戴、拒绝与带装扮的 `sprite`、`frame`；schema 校验覆盖新的动作、错误码与输入，并拒绝未知物品。
- 服务：经 `POST /v1/pets/me/actions` 穿戴，身体结构检查与物种一致。
