# 伙伴动作与表情规范

适用于所有稀有 AI 伙伴。规格取自 DeepSeek 原站鲸娘终阶的实测，GPT 成年形态是按它做出的第一个原创角色，后续角色以它为样板。

## 从 DeepSeek 量出来的规则

| 项目 | 实测 |
|---|---|
| 画布 | 69 × 66 像素；网页 6 倍显示，终端半块字符 69 列 × 33 行，两端同一份数据 |
| 角色 | 半身像，框约 49 × 48，放在 x 13–61、y 12–59；头与头发占大半，身体只露肩和手 |
| 脸 | 露出区域约 16 × 10；眼睛约 5 × 4（深色粗上睫毛加两层虹膜加高光）；嘴 2–3 像素；腮红 2 像素 |
| 配色 | 约 46 色；头发 3–4 个明暗阶；轮廓是极深色，只画在剪影和关键内线 |
| 剪影 | 头饰、发饰、耳鳍、尾巴，不靠一个团块 |
| 片段 | 22 段，每段 6–24 帧；帧时长不均匀：停留 200–700 ms，过渡 60–100 ms |
| 头部 | 动作之间头最多偏 1 像素；表演靠脸、手和符号，不靠整体位移 |
| 符号 | 每个动作配一个很小的符号（思考泡泡、键盘与 `</>`、勾、叉、爱心、z、感叹号、汗滴），约 9 像素以内，放在头旁空白处 |

## 一个角色需要提供什么

1. **半身像**：49 × 48 的框，放在与上面相同的位置，保留该角色的识别部件。
2. **六种表情**（好奇、专注、害羞、喜悦、受惊、得意）与眨眼、闭眼：只换眼睛、嘴和腮红，其余不动。眼睛两只一起变。
3. **每个动作一段独立片段**，有各自的帧数与时长；不得用同一张图整体平移冒充。
4. **符号库**：动作用到的符号集中放在同一处，位置固定在头旁空白。
5. **可替换的来源**：帧由脚本生成，也可以换成手绘 PNG 帧；运行时只认编码后的帧数据和时长表，不依赖生成方式。

另有六个**表情片段**（`exp_curious` 等，各 6 帧）：只对待机与观察生效，作用是把脸固定成所选表情并配一个小符号；任务动作保持各自设计好的脸。

## 规则

- 生命状态优先：`sick`、`evolve`、`end`、`sleep` 姿态会覆盖临时动作与表情。
- 一段片段按墙钟时间采样（宿主每 100 ms 一刻），所以不均匀的帧时长被保留；`end` 固定在第一帧。
- 宿主事件只驱动呈现，不修改养成数值。
- 未完成的角色或阶段一律返回 `bad_input`，不显示草稿。

## 制作与检查

```sh
python3 scripts/assets/import-gpt.py                          # 重新生成 data.rs 与 frames.bin
python3 scripts/assets/import-gpt.py --sheet out.png idle work  # 画接触表检查（需要 Pillow）
```

生成器在 `scripts/assets/gpt/`：`figure.py`（半身像与表情）、`props.py`（符号）、`clips.py`（片段表）、`compose.py`（摆放与部件位移）。验收时把每个片段逐帧放大看，并和 DeepSeek 同尺寸并排对照。

**当前状态**：GPT 成年的初稿已能完整跑通 26 个动作、六种表情，网页、终端与三端一致性测试都通过；绘画质量还没有达到原站鲸娘的水平（发丝与明暗偏机械、手的细节少），需要美术逐帧精修后再作为定稿。
