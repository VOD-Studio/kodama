# 物种目录与美术动作基线（R-05）

#6 的评审输出。**终端与像素画风达到「就绪」；精细画风尚未开始。** 终端形象是字符画的基线，用来固定目录结构、动作集和校验方法，不代表最终视觉质量，也没有经过视觉评审。旧吉祥物界面不是基线。

## 目录

`assets/catalog/species.json` 是素材清单，由 `crates/core/pet-term/tests/catalog.rs` 校验。每个物种声明：稳定编号与键、类别、身体结构、辨识特征、各画风的状态、各画风实际覆盖的动作、来源、作者与许可。

| 编号 | 键 | 类别 | 身体结构 | 辨识特征 |
|---|---|---|---|---|
| 0 | `ember-fox` | 幻想 | 行走 | 尖耳、四足行走 |
| 1 | `cloud-wisp` | 幻想 | 悬浮 | 云状身体，没有脚 |
| 2 | `house-cat` | 现实宠物 | 行走 | 须与尖耳、尾巴 |
| 3 | `house-dog` | 现实宠物 | 行走 | 垂耳 |
| 4 | `boxy-bot` | 机械 | 行走 | 方形头、双足 |
| 5 | `hover-drone` | 机械 | 悬浮 | 双旋翼，没有脚 |
| 6 | `sprout` | 自然（植物） | 扎根 | 叶冠，原地摇摆 |
| 7 | `ember-sprite` | 自然（元素） | 行走 | 火冠 |

四类生物方向各有两个样例，类别与稀有度互相独立（PRD：不把某一类固定为高稀有度）。

## 动作集与身体结构

PRD 要求的 11 个动作：待机、眨眼、移动、观察、进食、玩耍、睡眠、受惊、生病、进化、生命终结。终端画风全部实现；眨眼由呈现时钟自动产生。

移动**随身体结构变化**，不是给所有物种套同一套走路动画：

| 结构 | 移动方式 |
|---|---|
| 行走 | 左右行走并上下起伏一格，下半身两帧交替 |
| 悬浮 | 左右漂移，起伏两格，下半身不出现腿部字符 |
| 扎根 | 不位移，下半身两帧交替摇摆 |

## 校验器能抓到什么

10 项测试，其中几项做过变异检查：

| 检查 | 变异验证 |
|---|---|
| 编号恰好覆盖全部物种，键唯一 | |
| 四类方向齐全且每类不少于两个 | |
| 声明的身体结构与渲染器一致 | |
| 声明为就绪的画风必须覆盖全部 11 个动作，计划中的画风不得声明动作 | |
| 每个物种每个姿态都真的渲染出内容 | |
| **任意两个物种在不看颜色时可区分**（待机序列互不相同，静态轮廓互不相同） | 把物种 3 换成物种 0 的设计，测试失败 |
| **同一物种的任意两个动作在不看颜色时可区分** | 发现生病与终结只差颜色，已改为终结坐在纪念台上 |
| 移动符合结构：行走与悬浮会位移，扎根不位移但会摇摆；悬浮者没有腿 | 给悬浮者加上腿，测试失败 |
| 许可在允许集合内，来源与作者非空 | |
| 极小区域对所有物种与姿态都不 panic | |

「不看颜色也能辨认」对应 PRD 对素材的要求：不能只依赖细微色差区分个体。

## 来源与许可

八个终端形象由本项目原创，字符画直接写在 `pet-term` 源码里，因此体积为零额外资源。清单中声明为 **CC BY 4.0**（建议值，见 `distribution.md`）；代码部分为 MIT。第三方素材目前不存在。

## 未做

- 精细画风：属于 Web 渲染（#14），需要选定资源格式（SVG 或位图精灵）、骨架与槽位、锚点与层级。
- 生命阶段形象：像素画风已按阶段与分支区分外形（见 [evolution.md](evolution.md)）；终端画风的所有阶段仍共用一套字符画。
- 基因对外观的影响：字符画只有颜色随基因第一个字节变化；像素画风（含终端半格画）由前三个字节决定主色相、明暗与点缀色相，第四个字节决定个体花纹，出生稀有度决定光效（见 [evolution.md](evolution.md)）。
- 物种数量只有 8 个，出生派生也固定为 8；扩充需要同步目录、派生与黄金向量，并提升规则版本（见 `versioning.md`）。
- 精细画风的性能门槛、资源体积预算；像素画风体积为零资源（模板写在 `pet-term` 源码里）。

## 像素画风（`sprite`）

已按[进化形态与像素画风](evolution.md)重做：每个物种三个阶段各一副身体，进化分支带来不同特征，成年保留少年特征，每个物种 16 种外形；描边与明暗按统一规则生成；每个姿态是多帧动作，进化是前后外形交替闪烁的动画。外形体系、动画、校验与预览方式见该文。

`sprite` 命令返回调色板与像素网格，键为单个字符，`.` 为透明；呈现方按整数倍放大，不做插值。全部整数运算，三端输出逐字节一致。
